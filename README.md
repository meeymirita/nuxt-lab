# Nuxt Lab — Help Center

![Nuxt](Nuxt.png)

> Заглушка — методичка ещё не написана.

Публичный центр поддержки на Nuxt 4 + TypeScript: база знаний (SSG), статус сервисов (SWR), обращения клиентов (SSR с сессией), кабинет агента (SPA). Nitro server routes, SQLite + Drizzle, Zod-схемы в `shared/`, nuxt-auth-utils, Pinia, Nuxt Content v3, Vitest + @nuxt/test-utils, Docker Compose.

Методичка появится в `Nuxt_Lab_HelpCenter.html`.
